# Machine_Vision

机器视觉课程 课堂测试

## 目录结构

```
machine_vision/
├── src/        代码：paperclips.cpp（回形针计数）、coins.cpp（硬币计数）、holes.cpp（圆孔检测计数）
├── images/     图片：原图、二值化图、结果图
├── CMakeLists.txt
└── build.bat   一键编译并运行（MSVC + OpenCV 4.13）
```
